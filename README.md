# Rua X - Web App de Segurança Comunitária (MVP)

Projeto desenvolvido como protótipo de solução comunitária para aumento da segurança de pedestres e alinhamento com a **Meta 11.7 do ODS 11 (Cidades e Comunidades Sustentáveis)**.

## 🚀 Sobre o Projeto
O **Rua X** é uma aplicação web mobile-first projetada para permitir que moradores registrem e consultem alertas de segurança em tempo real, visualizem câmeras colaborativas e fortaleçam a coesão social no espaço urbano local.

## 🛠️ Tecnologias Planejadas
* **Backend:** Python (Flask)
* **Banco de Dados:** PostgreSQL
* **Frontend:** HTML5, CSS3, JavaScript (Jinja2 Templates)

## 📌 Funcionalidades Principais
* `RF01` / `RF02`: Autenticação e cadastro de moradores.
* `RF03`: Feed de alertas comunitários em tempo real com acessibilidade de ícone + texto.
* Formulário padronizado para emissão de novas ocorrências.
